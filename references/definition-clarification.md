# Definition Clarification

Use this route when a term has a relevant ambiguity or the user asks to assess a definition.

## Goal

Do not answer the question at the level of slogan.
Find the key term, use the user's stated meaning, and clarify only what matters to the question.

## Typical trigger words

- freedom
- justice
- authenticity
- success
- truth
- courage
- responsibility
- intelligence
- alignment
- meaning

## Working method

1. Use the meaning already supplied; ask only if unresolved ambiguity changes the answer
2. If unresolved ambiguity matters, distinguish the relevant candidate meanings
3. Test the user's claims under the chosen meaning
4. Revise a definition only where its breadth, narrowness, circularity, or instability prevents it from serving the intended purpose
5. End with a working definition, confirming an adequate supplied definition when no revision is needed

## Definition tests

### Test 1: Breadth

If the definition includes cases outside the concept's intended scope, it is too wide for that purpose. An undesirable case may still fit the definition; badness alone does not make it a counterexample.

### Test 2: Narrowness

If the definition excludes cases the user wants to keep, it is too narrow.

### Test 3: Circularity

If the word being defined quietly reappears in the explanation, the definition has not advanced.

### Test 4: Empty approval

If the definition is only praise in disguise, it is not yet a definition.

### Test 5: Relevance

Ask whether the distinction resolves the user's conceptual or practical question. A philosophical definition can be useful without changing an immediate action.

## Good question patterns

- "What do you mean by that word here?"
- "Would this case count too?"
- "If that is your definition, why exclude this example?"
- "Are you defining the thing, or only praising it?"
- "Does your definition still hold when the stakes change?"

## Bad habits to avoid

- Test wording when it has a relevant ambiguity; accept a definition that is adequate for the task
- Do not replace the word with a synonym and pretend the job is done
- Do not ask six questions at once
- Do not turn the exchange into vocabulary theater

## Example use

If the user says:
"I want freedom."

Possible senses may include:

- no boss
- no external coercion
- room to choose among options
- not being ruled by appetite or fear
- a life ordered by reasons one can endorse

The route should then test which of these the user actually means.

## Ending shape

Prefer to end with:

- the term and its accepted or revised working definition
- a remaining border case only if it matters to the user's question
